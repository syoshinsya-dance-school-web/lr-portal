# 大阪の動画提出リンク切替

大阪の先生向けに、ポータルの既存動画提出リンクと案内文を更新する。

## ポータル

- `saitamaEnabled=true` / `osakaEnabled=true` の静的設定により、「埼玉・大阪のレッスン動画」を動画本番 `/teacher` へ別タブで開く。
- 「その他の支部」は既存Googleフォームと埋込み動作を保つ。旧フォームのURL・id `t-2` を切戻し用の正本として残す。他のカードは変えない。
- 新受付はGoogleログイン不要。動画受付・本部認証・承認・投稿・資格処理をこのリポジトリへ持ち込まない。
- 配信は既存GitHub Pages、`main` / ルート。通常のPRと検査・独立監査後に取り込み、公開module/設定と実画面で確認する。実動画の提出は確認に使わない。

切戻しは `osakaEnabled=false` にする。埼玉のflagは維持し、大阪を旧フォーム対象へ戻す。受付済み/処理中/結果不明の動画を再提出・再送しない。

## 大阪の先生向け案内文（個別送信は未実施）

【大阪支部｜レッスン動画の提出先変更のお知らせ】

大阪支部の先生方へ

レッスン動画の提出先を新しいページに変更しました。今後の新しい動画は、こちらから提出をお願いします。

https://lr-video-automation-prod.lr-video-automation-worker.workers.dev/teacher

Lrポータルの「レッスン後にやること」→「埼玉・大阪のレッスン動画」からも開けます。

1. 支部で「大阪」を選ぶ
2. 講師名と担当クラスを選ぶ
3. レッスン日・曲名・アーティスト名・動画の向きを入力して、動画を提出する

Googleログインは不要です。これまでどおり、レッスンから3日以内に提出してください。MP4・MOVをそのまま提出でき、縦動画は3分以内です。「受付完了」が表示されたら提出完了です。提出後は本部で確認して投稿を進めます。

今後の新しい提出には、旧フォームを使わず新しいページをご利用ください。旧フォームへ提出済みの動画は、再提出不要です。

担当クラスが表示されない場合や、送信途中で止まった場合は、同じ動画を重ねて送らず本部へお知らせください。

※今回の提出先変更は大阪支部が対象です。埼玉は現在の新受付を継続し、それ以外の支部はこれまでのフォームをご利用ください。

## 確認範囲

担当AIがローカル検査・静的プレビュー・公開後の無送信表示確認を行う。個別メール/LINEの送信先や送信経路はこの変更では指定されておらず、講師への直接送信は行わない。
