# Lrポータル 最新仕様

更新：2026-11-28 JST。富田さんとCodexの会話で確定した修正を統合した、ポータル実装仕様の正本。

## 目的・担当

目標は「覚えていなくても正しく動ける」。必要な入口へ少ないタップで進み、短い動画・要点3つ・実行ボタンをつなぐ。

- 富田：目的・優先順位・内容と公開範囲の最終判断。
- Codex：富田と直接相談して仕様更新、実装、掲載、検証、記録を担当。別AIへ実装指示を回す工程を挟まない。
- 動画制作AI：台本・動画・要点3つを制作して納品。コードや最新仕様の管理は担当しない。
- 独立監査：実装者の確認とは別に扱う。必要な節目では人の管理のもとで受け渡す。

## 新旧の共存と共有動画

新旧を併用する。旧の普段の入口にも納品動画を追加し、移行前に講師を新トップへ強制誘導しない。旧 `index.html` は既存カテゴリや業務先を維持し、明示された表示修正だけを行う。

動画は `videos/` 内に固定名で1ファイルだけ置き、新旧・必要な生徒案内から同じファイルを参照する。差し替えは同じパス・同じ名前で内容のみを更新する。通常のブラウザキャッシュによる一時的な旧版表示は許容し、確認時は再読込する。

最終配信先はGitHubリポジトリ＋GitHub Pages。一般公開の配信先なので、講師用と書いたページやリンクを隠すだけでは閲覧制限にならない。公開可能な素材だけを掲載する。非公開教材の配信が必要ならアクセス制御可能な別方式を検討し、勝手に公開しない。

生徒に見せる動画は、講師の操作ページとは別の固定案内ページから開けるようにする。QRはMP4の直リンクや期限付きURLではなく案内ページを指す。想定パス `guide/nyuukai.html` は現在未配信で、ページ制作・料金等の要点確定・QR/PDF制作は別工程。基本システムMP4は生徒向けでもあり、講師も共通の動画を確認できる。生徒向け案内の作成と公開範囲は富田の内容確認後に確定する。

## Lrの基本：3カテゴリの地図

`Lrの基本 → カテゴリ → 動画詳細` の3階層。新ポータルはその入口。カテゴリタイルは動画数によらず全部見せる。2〜3本そろうまで隠す旧方針は廃止。

| 分類 | 色 | 含むテーマ |
|---|---|---|
| 日々やること | 緑 | 体験日報、チェックイン、動画/写真の撮り方と提出、課題曲提出。サブ枠「最初だけやること」にLINE WORKS初期設定・新入会生徒の招待 |
| レッスン | 紫 | 当日の進め方、振り落としの時間、体験者対応。感動マニュアル・人気の先生になれるBOOKは当面PDFとして扱う予定 |
| 生徒に聞かれるし間違えてはいけないこと | 青 | 料金・月謝、振替チケット、回数制、退会 |

3番目の長いカテゴリは2列分の幅を使う。未納品項目はカテゴリ内に小さいテキスト1段落の予告としてまとめる（狭い画面では自然折返し）。準備中のフルカードや偽の再生ボタンは作らない。納品後は該当テーマを予告から外し、タイトル・所要時間・小サムネイルの横型カードを表示する。

流れ総覧の空パネルやアンカーチップは置かない。サブ枠は余分なページ階層を増やさない。01.Lrとは/08.インスタマニュアルは今回の体系化に含めない。紙日報の記入見本・旧Googleドキュメント手順は廃止。

詳細の型は動画1本→実行ボタン→要点3つ。要点は確認済みの納品内容を使い、Codexが業務ルールを補作しない。正式ルールとして将来CS/AIに共有する構想はあるが、自動配信や承認システムは未実装。育成担当は動画と元マニュアルを併用し、食い違いは富田経由で制作物と正本を修正する。

## FAQとの関係・別依頼の確定ルール

FAQは短い即答として維持する。3ステップ以上の手順や誤案内の影響が大きい項目は動画化し、対応動画がそろった段階で相互リンクする。動画がない段階で架空リンクを置かない。

別依頼として本番FAQの振替ルールを修正済み：60分・90分とも欠席時に振替チケット付与、欠席したレッスンは2ヶ月以内に振替可。それとは別に毎月1枚、休んでいなくても使えるチケットを付与（有効期限2ヶ月）。FAQの3-3/3-4/9-2とデータ再取得の変更は `lr-faq` repo側。ポータルの改修でこの別repoを上書きしない。
