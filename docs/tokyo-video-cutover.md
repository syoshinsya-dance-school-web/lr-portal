# 東京の動画提出リンク切替

東京の新しい動画提出受付が開通したことを確認してから、`videoSubmission.tokyoEnabled=true`を配信する。埼玉・大阪の設定と、その他支部の旧フォームURL・埋込み動作・他カードを保持する。

「埼玉・大阪・東京のレッスン動画」は既存の本番 `/teacher` を別タブで開く。支部・講師・担当クラスの選択は動画受付側が扱い、このポータルには複製しない。切戻しは `tokyoEnabled=false` のみ。埼玉・大阪を新受付へ案内する設定は維持する。

## 東京の先生向け案内文（個別送信は未実施）

【東京支部｜レッスン動画の提出先変更のお知らせ】

東京支部の先生方へ

今後の新しいレッスン動画は、こちらのページから提出をお願いします。

https://lr-video-automation-prod.lr-video-automation-worker.workers.dev/teacher

Lrポータルの「レッスン後にやること」→「埼玉・大阪・東京のレッスン動画」からも開けます。

1. 支部で「東京」を選ぶ
2. 講師名と担当クラスを選ぶ
3. レッスン日・曲名・アーティスト名・動画の向きを入力して提出する

Googleログインは不要です。これまでどおりレッスンから3日以内に提出してください。MP4・MOVをそのまま提出でき、縦動画は3分以内です。「受付完了」が表示されたら提出完了です。その後、本部で確認して投稿を進めます。

今後の新しい提出には新しいページをご利用ください。旧フォームへ提出済みの動画は再提出不要です。

担当クラスが表示されない場合や、送信途中で止まった場合は、同じ動画を重ねて送らず本部へお知らせください。

今回の変更対象は東京支部です。埼玉・大阪は現在の新受付を継続し、それ以外の支部はこれまでのフォームをご利用ください。

## 検査と公開

`node --test tests/video-submission.test.mjs`で東京の単独有効化/切戻し、既存支部と旧フォーム/他カードの保持を検査する。既存GitHub Pagesの通常PRで反映し、配信設定と実画面の導線を無送信で確認する。個別メール・LINEは送信しない。
