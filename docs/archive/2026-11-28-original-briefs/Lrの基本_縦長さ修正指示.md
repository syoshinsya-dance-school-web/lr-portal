# 「Lrの基本」ページ 縦長さの修正指示（Codex向け）

対象: `lr-portal/basics/index.html` と `lr-portal/assets/learning.css`
背景: 試作を見たユーザーから「縦に無駄に長い」「わかりにくい」「戻り方が直感的ではない」との指摘。実物を確認したところ、主因は中身ではなく「準備中カードの積み重ね」と「飛んだ先からの戻り導線のなさ」だった。縦スクロール＋ボタンでジャンプする方式自体は維持でよい（ユーザー確認済み）。

## 修正1（最優先）: 準備中カードを並べない。ただし地図は見せる

- 現在、12枚中11枚が「準備中」カードで、1枚ごとにバッジ＋見出し＋説明文のフルサイズ表示になっている。これだけで1,000px以上のスクロールになっている。
- 準備中のテーマは、カテゴリごとに1行の小さなテキストでまとめて表示する（例:「準備中: チェックイン／動画の撮り方・提出／課題曲の提出」）。カード形状にはしない。
- 注意（2026-11-27夜の試作で判明）: 逆に「中身のないものは全部隠す」と、今度はスカスカで全体像（何がある場所なのか）が分からなくなる。カテゴリのタイル自体は常に見せて「地図」を示し、隠すのは詳細の中身だけにする。非表示にしてよいのは、予告の1行すら置く意味がない場合だけ。

## 修正2: 構造を FAQ サイト型の「親 → 中間 → 詳細」タイル階層にする（ユーザーの希望形）

ユーザーの希望: 「□□／□□ とタイルが並んでいて、タップしたら1つの動画（詳細）に飛ぶ。親―中間―詳細の分岐があるといい」「要は Web の FAQ みたいな見やすさ・戻りやすさ」。つまり FAQ サイトの定型（カテゴリ → 一覧 → 回答ページ＋パンくず）を、回答の代わりに動画でやる形。現状の「全カテゴリを1ページに縦積み＋アンカージャンプ」はやめ、次の3階層に統一する。ポータルトップのカテゴリグリッド（2列タイル）が既にこの形なので、それを「Lrの基本」の中にもそのまま持ち込む。

- **親**: ポータルトップ（既存のタイルグリッド）。
- **中間-1**: 「Lrの基本」トップ = カテゴリのタイルグリッド（2列）。レッスンの流れ／やること／生徒に聞かれたら／はじめにやること／先生の心得。1画面に収める。
- **中間-2**: カテゴリページ = そのカテゴリのテーマのタイルグリッド（例: やること → 日報／チェックイン／動画提出／課題曲）。個別ページにする（例: `basics/tasks.html`、`basics/student.html`）。
- **詳細**: テーマページ = 動画1本＋実行ボタン＋要点3つ。nippo-taiken.html が既にこの形なので、型として統一する。

ルール:

- 1画面に置くのは「タイルの並び」か「動画1本」だけ。複数カテゴリを1画面に縦積みしない。アンカーチップ（category-nav）は廃止する。
- 階層は3段まで。それ以上深くしない。
- **戻るは常に「1つ上の親へ」**: 各ページの上部に親の名前で戻るボタンを置く（例: 詳細ページは「← やることへ」、カテゴリページは「← Lrの基本へ」）。詳細ページは下部にも同じボタンを置く（動画と要点を見終わった位置で戻れるように）。戻る＝1段上がる、が全ページで同じ動きになるので迷わない。
- **パンくずを全ページ上部に出す**: 「Lrの基本 ＞ やること ＞ 体験があった日の日報」の形。各階層名がそのままリンクになっていて、現在地が分かり、どの階層へも1タップで戻れる。FAQサイトの戻りやすさはこのパンくずが担っている。
- タイルには「テーマ名＋所要時間（▶ 58秒）」だけを出す。説明文は詳細ページに寄せる。

## 修正3: 「レッスンの流れ」総覧パネルをなくす

- 総覧動画ができた時点で「やること」の先頭カードとして置く。それまではセクションごと出さない。

## 修正4: 見られるカードを横型コンパクトにする

- サムネイルを左に小さく（幅120px程度）、右にタイトル＋1行説明＋所要時間の横型レイアウトにする。

## 修正5（ついで）: 余白を詰める

- これは仕上げ調整で、修正1〜2ほどの効果はない。優先度は最後。

## 追加: 掲示板（ポータルトップ）の扱い

ユーザー指摘: 掲示板も分かりにくく、情報が拾いきれない（埋もれる）のではないか。そもそも掲示板を無くす手もあるのでは。

現状（portal-data.json 実測）: 5カテゴリ・23項目が目的混在のまま平たく並んでいる。

- レッスン後にやること（実行系）3件
- ルール・マニュアル関連（参照系）3件
- レッスン動画（素材系）12件 ← 説明文なし・似たタイトル（ストレッチ例が先生別に4本など）で、ここが埋もれる主因
- 申請関係（実行系）3件
- 生徒から質問されたら？（参照系）2件

方針: 「全部を平たく貼る掲示板」の形はやめる。ただしポータル（入口）自体は残し、中身を目的別に分解する。

1. **実行系はトップに残す**: レッスン後にやること＋申請関係は、トップ上部の大きな実行タイルにする。数は絞り、「今日やること」が一目で分かる状態を保つ。
2. **手順・ルール系は「Lrの基本」へ移行**: FAQ型の階層に吸収する。運営マニュアルのような「読む資料」へのDriveリンクは置かない（講師は読まない。動画化して詳細ページに置く。第7章の体系化と合流）。
3. **レッスン動画は「レッスン素材」として独立させる**: 中間を種類別（ストレッチ／筋トレ／アイソレーション／リズムトレーニング／見本）に分け、先生別はその下に置く。各動画に1行説明（レベル・分数・対象）を付ける。
4. **お知らせは掲示板に貼らない**: 見落としが困る連絡は「見に行く場所」に置いても拾いきれない。講師の日常導線であるLINEで流す。ポータルは「必要なときに自分で引きに行く場所（実行と参照）」に限定する。

## 追加2: ポータルトップの画面遷移（「移動している感じ」の解消）

ユーザー指摘: ポータルトップ（index.html）が「なんか移動している感じがする」。実物コードを確認したところ、原因は次の4つ。

1. 画面が丸ごと切り替わる方式（カテゴリ一覧 → 項目一覧 → 埋め込み表示）で、切り替わるたびに自動で一番上へスクロールする。
2. 項目によって遷移先がバラバラ: リンク系は別タブ、フォーム・ドキュメント・動画はその場で iframe 埋め込み。タップするまで行き先が予測できない。
3. iframe 埋め込みは Google ドライブ等の読み込み待ちが発生し、待たされる感覚が強い。
4. 初回表示で「読み込み中…」が出てからタイルが描画されるため、レイアウトが動いて見える。

直し方:

- トップは「1画面にタイルが安定して並ぶ」だけにする。画面内のビュー切り替え（カテゴリ→一覧の SPA 遷移）はやめる。
- 遷移は全項目で統一する: タップ → 詳細ページへ移動（FAQ型の階層）。別タブで開く項目と埋め込み表示の項目を混在させない。外部フォーム等も、詳細ページ側に置いたボタンから開く形に寄せる。
- 戻るはパンくず＋「1つ上の親へ」ボタンで統一する（修正2と同じルール）。
- 初期表示の「読み込み中…」→タイル出現のレイアウト移動をなくす（データをページに埋め込むか、タイルの枠を先に描く）。

## 追加3: 社内FAQページ（lr-faq）の確認結果と統一

実物を確認した（2026-11-27）。トップはタイルグリッドで1画面に収まり、全30件・回答は1行中心で軽い。目指す形に一番近いのはこのFAQページなので、ポータル／Lrの基本はこの型に寄せて統一する。ただしFAQ側にも次の引き継ぎ事項がある。

1. **ブラウザの「戻る」が効かない**: ポータルと同じSPA方式（URLが変わらないページ内切替）なので、ブラウザの戻るを押すとサイトを離れてしまう。スマホ／LINE内ブラウザで開く講師が最も使う戻り方がこれなので、実ページ遷移にするか、最低限 History API で戻るが効くようにする。
2. **パンくずがない**: 質問一覧の画面にカテゴリ名の見出しすらなく、「← トップに戻る」からしか現在地が分からない。パンくず＋カテゴリ見出しを付ける。
3. **内容の食い違い（解決済み・FAQ側を直す）**: FAQ「振替のルールは？」の回答「1ヶ月以内に振替が可能。振替は1回まで。」は誤り。ユーザー確認（2026-11-27）: 正しいのはシステム説明動画で採用したルール。FAQの回答を次の文案に差し替える。
   - 修正文案: 「欠席したレッスンは2ヶ月以内に振替できます。ほかに毎月1枚、振替チケットがあります。チケットは休んでいなくても使えます（有効期限2ヶ月）。」

## 目標の状態

- 「Lrの基本」を開いたら、見られるもの（今は日報）へすぐ手が届き、準備中が視界を埋めない。
- どの位置からでも、カテゴリ移動と「戻る」が1タップで迷わずできる（固定チップ＋現在地表示＋セクション末尾の戻るボタン）。
- 日報カードまで: ポータル → Lrの基本 → やること → 日報、の3タップ。日報ページ自体の中身は現状のままでよい（動画＋ボタン＋要点3つで完結）。戻る導線だけ下部にも追加する。
- 講師はスクロールが長いページを読まない前提。「覚えていなくても正しく動ける」が判断基準。
