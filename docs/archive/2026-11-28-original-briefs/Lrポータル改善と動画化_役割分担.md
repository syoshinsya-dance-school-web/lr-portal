# Codexへの依頼書 ― Lr講師ポータルの改善とルール動画の置き場所づくり

作成：2026-11-26（亮 → Codex）／ 改訂：同日、改善案への5つの追加を反映 ／ 改訂2：2026-11-27、講師用マニュアル一式の体系化（第7章）を追加し、動画の制作状況と優先順位を更新 ／ 改訂3：2026-11-27、「Lrの基本」のカテゴリ構成を3分類（日々やること／レッスン／生徒に聞かれるし間違えてはいけないこと）に変更し、FAQとの関係と育成担当の併用を追記

## 0. 前提と目標

- 講師は「考えない・感覚派・非社会人タイプ」が多く、文章のルールは読まれないし覚えられていない（社長方針：ルールは基本的に動画化する）。
- **目標は「全部覚えてもらう」ではなく「覚えていなくても正しく動ける」に置く。** 改善の優先順位はこの目標で判断する。
- ポータルの役割は「タップしてすぐ見られる／すぐできる」こと。読ませる作りにしない。
- 対象：https://syoshinsya-dance-school-web.github.io/lr-portal/

## 1. 進め方の原則

### 1-1. 「URL先行・ファイル差し替え」方式
- ボタン・ページ・動画の置き場所は、まず試作として**最終形のURLのまま**先に作って公開する。
- 動画の中身は後から何度でも差し替える。その際、**ファイルのパスと名前は絶対に変えない**。中身だけを置き換える。
- 差し替え直後はブラウザキャッシュで古い動画が見える場合があるが、通常運用では問題としない。

### 1-2. QRコードは「固定の案内ページ」へ向ける
- QRのリンク先は動画ファイルそのものではなく、**固定URLの案内ページ**にする。
- ページ内の動画・要点・補足は後から更新できる。料金変更などで旧版の内容が表示されていないかも、更新時の確認対象とする。

### 1-3. 動画には必ず「操作ボタン」と「要点3つ」を付ける
- 動画の直後に、そのまま実行できる操作ボタンを置く（例：「日報の説明を見る → 日報を出す」）。見ることから実行までを切らない。
- 動画の下に「要点3つ」をテキストで残す。毎回再生しなくても確認できるようにするため。
- この「要点3つ」は正式ルールのテキストとして扱い、社内ログ収集ボット／AIが参照するルールの置き場にもなる。

### 1-4. 「講師が学ぶ動画」と「生徒に見せる動画」を分ける
- 講師用：ポータルの「Lrの基本」の中（ルール・手順の学習用）。
- 生徒用：QRから開く生徒向け案内ページの中（クロージング等で見せる用）。
- 今回のシステム説明動画（`lr-system-guide.mp4`）は**生徒用**として配置する。
- ただし、講師自身もシステム（料金・振替など）を分かっていないことがあるため、講師ポータル側からも同じ動画を見られるように置く（2026-11-28追加決定）。置き場所は次の通り（同日、ユーザーの画面イメージで確定）:
  - 旧ポータル: トップの「よくある質問（FAQ）はこちら」バナーの横に、「基本システム」バナーを並べて置く（半幅ずつ）。タップで動画が再生される形。
  - 新ポータル: 「Lrの基本」ページの一番上に、3カテゴリのタイルとは別枠の横長バナーとして置く（カテゴリに混ぜると埋もれるため、別枠で目立たせる）。
  - ファイルは生徒用と同一の1本（`videos/lr-system-guide.mp4`）を参照し、二重に持たない。

### 1-5. 最初は1テーマで効果を見る
- 講師用動画は、まず「体験があった日の日報」1テーマで試す。
- 社内ログ収集ボットのデータで、同じ質問や提出漏れが減ったかを確認してから、対象を広げる。

### 1-6. リリースは「新ポータルのガワ＋新旧両方に掲載」（2026-11-27決定）
- 新ポータルは、完成を待たずにガワ（FAQ型の階層・タイル・パンくず）だけ先に作る。
- 動画は新ポータルにも旧ポータル（現行）にも両方載せる。講師の日常導線は旧ポータル側にあるため、新ポータルだけに載せると見られない。
- 動画ファイルは1つ（同じパス・同じ名前）を両方から参照する。二重に持たない。
- カテゴリの地図（全体像）は最初から見せる。ただし中身がまだない項目は、フルサイズの「準備中」タイル・カードにはせず、カテゴリページ内に1行の小さいテキストで予告するだけにする。（2026-11-27夜の試作で、逆に「中身のないカテゴリは全部隠す」とスカスカで全体像が分からなくなったため、この形に修正）

## 3. フェーズ2（ポータル全体の改善）

### 3-1. ログインの壁の解消
- 「Lr運営マニュアル」「人気の先生になれるBOOK」「レッスン動画12本」がGoogleドライブ依存で、未ログインだと動画が再生できない。

- マニュアル類は、動画化が完了した項目から文書リンクを動画リンクへ置き換える。

- トップに固定ボタン「🆘 困ったらここ（運営に連絡）」を追加し、タップで電話（050-1725-8157）または運営LINEへつながるようにする。

- FAQサイト（lr-faq）からポータルへ戻るリンクを追加する。
- よくある質問の上位はポータル側にも直接置き、回答まで2タップ以内にする。

### 3-4. 文言・表示の統一
- 「埼玉のレッスン動画」カードの説明文は、実態に合わせて**「Googleログイン不要で提出・履歴確認」**に修正する（決定事項）。

## 5. クマの動画制作（参考）

### 制作フォーマット（確定済み）
- マスコットキャラ（サラン君）が吹き出しで案内する、スライド＋AIナレーション＋字幕＋BGMの形式。
- 1本あたり30秒〜1分半。文字は大きく少なく、専門用語なし。
- 完成MP4はWeb用ファイル名（半角英数）で納品する。

### 制作済み
- `lr-system-guide.mp4`（生徒用）― Lrのレッスンシステム説明。クロージング用、約1分23秒。
- `lr-nippo-taiken.mp4`（講師用）― 体験があった日の日報。実画面入り、約58秒。結果の6選択肢は実画面の表記（来た・入会したい／来た・入会検討中／来た・入会見送り／来た・入意思未確認／無断キャンセル／事前キャンセル）に合わせた。hacomonoで入会登録されると自動で「入会済み」表示になり、ボタン操作は不要という補足を含む。

### 制作予定（優先順）― 第7章のマニュアル体系化に対応（2026-11-27 改訂3で順序変更）
操作系の細かい操作は実は難しくないため、次はレッスン系を先に作る（ユーザー決定）。

1. **体験者への対応**（レッスン系。元：感動マニュアル「ダンスレッスンシーン別対応」の体験者パート）― 次に制作。ファイル名 `videos/lr-taiken-taio.mp4`
2. チェックインのやり方（元：07.先生向け出欠席確認マニュアル）― 毎日使う操作で、当日中に押さないと欠席扱いになる
3. 「生徒に聞かれるし間違えてはいけないこと」系4本（元：かんたんマニュアル）― 料金・月謝／振替チケット／回数制／退会。元がスライド形式のため動画化が速い
4. 「最初だけやること」2本（日々やること配下。元：LINE WORKSマニュアル）― 初期設定／新入会生徒をグループLINEに招待
5. 動画の撮り方・提出と課題曲提出（元：Lrルール書の該当ページ）
6. 振り落としの時間について（レッスン系。感動マニュアル／ルール書から新規に起こす）
7. トラブル時の動き（遅刻・休講・クレーム）
8. 申請のやり方（交通費・課題曲報告・枠のオープン／クローズ）

※台本は第7章の元マニュアルをもとにクマが作成し、亮さんが確認してから完成版にする。

## 6. 申込用紙のQRコードについて

- フェーズ1で生徒向け案内ページが公開されたら、クマがそのページURLのQRコードを生成し、申込用紙PDFに「入会前にご覧ください」の一文とともに合成した印刷用PDFを作成する。
- QRのリンク先は恒久URLの案内ページに限る（期限付きリンクや動画ファイル直リンクは使わない）。
- 以後の内容修正はページと動画ファイルの差し替えで行い、QRコードは刷り直さない。

### 7-3. 対象外・廃止（決定事項）
- **01.Lrとは（5p）**：理念・スクール紹介。新人オリエンテーション用として現行のまま残し、今回の体系化には含めない。
- **08.インスタマニュアル（1p）**：講師個人アカウント・ライブ配信の話で日常手順とは別枠。体系化には含めない。
- **06.240314書き方見本（1p）**：紙日報時代の記入見本。デジタル日報に移行済みのため廃止。
- **【講師用】体験日報・レッスン写真提出マニュアル（Googleドキュメント）**：旧手順。日報動画への差し替え対象（フェーズ1の旧カード差し替えと連動）。写真提出の手順は「動画の撮り方・提出」動画に取り込む。

### 7-4. 進め方と優先順位
1. Codex：「Lrの基本」を上記カテゴリ構成で組み、日報動画（納品済み）を配置する。
2. クマ：第5章の優先順で動画を制作・納品する（次はレッスン系「体験者への対応」）。
3. 効果測定は第1-5項の方針どおり、まず日報1テーマで様子を見る。対象を広げる判断は亮さんが行う。
4. **育成担当の指導でも使う**：育成担当が新人講師を教えるとき、この動画群を見せながら、元マニュアルも併用して教える運用とする。動画＝手順の正、マニュアル＝詳細の正。指導の場で食い違いに気づいたら、亮さん経由でクマ（動画）と元マニュアルの両方を直す。

### 7-5. よくある質問（FAQ）との関係
- FAQ（lr-faq）は今の粒度（テキスト1行回答）のまま残す。役割は「覚えておくべきだけど忘れがちなこと」の即答。
- ただし、手順が3ステップ以上あるもの・間違えると生徒対応に響くものは動画化して「Lrの基本」に置き、FAQの回答から動画へリンクする（例：振替について、SNSについて）。
- 分類3「生徒に聞かれるし間違えてはいけないこと」はFAQと内容が重なるため、FAQ側の該当回答には必ず対応する動画へのリンクを付ける。
